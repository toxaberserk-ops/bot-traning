# FitTrack - Telegram Mini App для тренера

Полнофункциональное приложение для управления клиентами фитнес-тренера через Telegram.

## 📋 Что работает

✅ **Админ-панель для тренера:**
- Просмотр всех клиентов (20-30 человек)
- Статистика по прогрессу каждого
- Отслеживание питания и тренировок
- Рекорды и графики прогресса

✅ **Личный кабинет клиента:**
- Добавление приемов пищи с расчетом калорий и БЖУ
- Логирование тренировок (кардио, силовая, круговая)
- Отслеживание прогресса к цели
- История всех данных

✅ **Интеграция с Telegram:**
- Уведомления тренеру о новых записях клиентов
- Красивый мобильный интерфейс
- Быстрый доступ прямо из Telegram

## 🤖 Настройка Telegram бота

### Шаг 1: Зарегистрировать Web App

1. Напиши **@BotFather** в Telegram
2. Отправь команду: `/setmenubutton`
3. Выбери своего бота из списка
4. Нажми кнопку "Web App"
5. Введи параметры:
   - **Text (текст кнопки):** `Открыть FitTrack`
   - **URL:** `https://твой-vercel-url.vercel.app` (твой URL с Vercel)

### Шаг 2: Настроить команды

1. Отправь **@BotFather** команду: `/setcommands`
2. Выбери бота
3. Скопируй и отправь:
```
start - Запустить приложение
help - Справка
status - Статус
```

### Шаг 3: Установить описание

1. Команда **@BotFather**: `/setdescription`
2. Выбери бота
3. Описание:
```
FitTrack - система управления тренировками и питанием для клиентов
```

## 🔑 Использование приложения

### Вход тренера:
- Нажми "👨‍🏫 Тренер"
- Пин-код по умолчанию: **1234**
- Видишь всех клиентов, их прогресс, питание и тренировки

### Вход клиента:
- Нажми "💪 Клиент"
- Выбери свое имя
- Добавляй приемы пищи и тренировки
- Тренер будет получать уведомления

## 📝 API endpoints

```
POST /api/login/trainer           - Вход тренера
POST /api/login/client            - Вход клиента
GET  /api/clients                 - Список всех клиентов (для тренера)
GET  /api/client/:clientId        - Информация о клиенте
POST /api/meal                    - Добавить прием пищи
POST /api/workout                 - Добавить тренировку
GET  /api/stats/:clientId/:date   - Статистика за день
POST /api/client/:clientId/update - Обновить цель/прогресс
```

## 🔐 Безопасность

## 🆘 Решение проблем

**Ошибка: "Cannot GET /api/clients"**
- Проверь что сервер запущен
- Перезагрузи страницу

**Бот не отправляет уведомления**
- Убедись что BOT_TOKEN правильный
- Проверь консоль в Vercel (Logs)

**Данные не сохраняются**
- На Vercel используется временное хранилище
- Для production нужна БД (Firebase, PostgreSQL)
